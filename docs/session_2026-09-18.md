### A real accessibility defect in the new UI, found and fixed

Yesterday's interface used `.system(size:)` for every font, which produces a
**fixed** point size that ignores Dynamic Type entirely. In an app for people
with low vision that is the wrong way round: a 12pt caption stayed 12pt for a
user who had already turned their text size up, so the interface was least
legible for exactly the people it exists for. Zero of its fonts scaled.

Every font now resolves a nominal size onto the nearest `Font.TextStyle`, so
the whole interface responds to Larger Text. The 62pt distance readout sits
above every text style, so it uses `@ScaledMetric(relativeTo: .largeTitle)`.
The dense monospace panels (decision trace, track list) are capped at
`accessibility2`, because a two-column label/value row stops being a row past
that; **the status card scales without limit**, which is where the budget
belongs.

## 4. Things not to undo

Carried forward, each looks like a simplification and is not.

- **`FrameGeometry.landscapeROI(forPortrait:)` is a rotation, not an axis
  swap.** Dropping the flip mirrors every sampled region and returns a
  plausible wrong number.
- **Frames must be rotated upright before detection.** 0 of 4 detected as
  stored, 4 of 4 rotated.
- **Urgency is `min(1, proximity + 0.35×ttc) × (0.6 + 0.4×hazard)`.** Not
  co-weights summing to 1 — that made the top band unreachable standing still.
- **`AVSpeechSynthesizer` stays out of the per-frame path.**
- **The 30 Hz cap is 0.030 s, not 1.0/30.0.** The latter is exactly twice
  ARKit's delivery period and aliases, costing a quarter of the frame rate.
- **Thermal comparisons use warm-phase frames only.** The all-frames
  comparison inverts the result.
- **`build_thesis.sh` flags every blockquote on purpose.** Do not narrow it
  back to a prefix list.
- **The status card's Dynamic Type is deliberately uncapped** while the dense
  panels are capped.
- **`results_long.csv` keeps the fallback-ROI rows** — they are the evidence
  for §4.2.1's coverage finding.
